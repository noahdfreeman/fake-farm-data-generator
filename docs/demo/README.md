# Verified fake-data demonstration

This directory contains a deliberately small, fully generated demonstration of
all four Fake Farm Data Generator data types. It uses fabricated field geometry
and retains the permanent fake-data warning in every generated artifact.

- Open [the interactive demonstration](index.md) to launch the portable review.
- Download `fake-farm-data-demo.zip` for the complete portable sample.
- Inspect `sample_run/run_manifest.json` for generated components, record counts,
  seed provenance, and completion status.

The demonstration includes soil-test points and an ordinary-kriging polygon
surface, planting center and row-unit logs, an as-applied operation, yield logs,
polygon-grid surfaces, and the split-screen HTML comparison viewer. No real
grower or agronomic records are included.
